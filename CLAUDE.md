# eats.mapmyhyd.com — house rules

## Copy / text
- **No em-dashes (—) in any user-facing text.** Applies to all copy: page text,
  venue content in `data/venue-content.json`, headings, blurbs, meta descriptions,
  UI strings in components. Use a comma, period, or rewrite the sentence instead.
  (Plain hyphens in compound words like `go-to`, `sweet-and-salty` are fine.)

## Design / CSS
- **No accent side-colour stripes on cards.** Do not add a coloured left/right
  border (e.g. `border-left: 4px solid var(--violet)`) to cards, callouts, or
  sections. Keep the full border a single neutral colour (`var(--line)`); use the
  badge/label for emphasis instead of a coloured edge.
