Weekly cadence: Monday discover and shortlist; Thursday verify, update the
ledger and prepare the next article revision. This is a publishing ceiling,
not a quota: skip a thin duplicate issue instead of inventing news.

Monthly cadence: one substantial recap, linked from the evergreen guide,
only when it contains meaningful new reporting. Weekly updates normally stay
on the established URL. Do not generate separate weekly slugs containing the
same venues, copied descriptions and a changed date.

## What each researched entry needs

- A named branch, an actual source URL, report date, and explicit opening date
  when the source establishes one. Keep unknown dates unknown.
- The specific food/format, supported menu examples, neighbourhood and map link.
- Real venue photography with appropriate credit; no fabricated restaurant imagery.
- Prices, hours, bookings and dietary claims only when verified, with the date.
- A clear distinction between an announcement, our visit review and local votes.
- One link to the relevant existing ranking or guide; no unrelated link stuffing.

## Automation and measurement

The existing Monday/Thursday recovery heartbeat should perform this research
alongside technical checks, save new leads and draft revisions, and refresh the
calendar only when the evidence changes. Keep account data and source dates
explicit. Research may use Agent Reach's Exa web backend; never use Google Search.

Notify for a newly verified opening worth covering, a changed publication
priority, a material search-performance change, a failed check or required user
action. Stay quiet for unchanged findings. Do not send outreach or automatically
publish future articles from unverified leads.

Measure guide and ranking URLs separately: finalized GSC impressions/clicks,
query groups, Google-selected canonicals, and real map opens/vote conversions
where analytics exists. Report missing telemetry as unavailable. Screenshots
already supplied by the user remain a dated baseline, not fresh weekly data.
